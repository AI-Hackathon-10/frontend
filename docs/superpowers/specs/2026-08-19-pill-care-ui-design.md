# 알약케어 반응형 프론트 UI 설계

## 목적

병원이나 약국에 바로 접근하기 어려운 사용자가 알약을 식별하고, 의약품 참고 정보를 확인하고, 증상을 정리하고, 가까운 응급의료기관을 찾는 흐름을 한 화면 체계 안에서 이해할 수 있도록 한다.

이번 단계는 Spring Boot/API 연결 전의 프론트 목업이다. 검색, 이미지 업로드, 위치 조회, 전화 연결은 실제 동작하지 않으며 화면 전환과 시각적 완성도에 집중한다.

## 범위

포함 화면:

- 홈
- 이미지로 알약 찾기
- 외형으로 알약 찾기
- 검색 결과
- 의약품 상세 및 주의사항
- 증상 문서화
- 응급의료기관 탐색

제외 범위:

- 실제 공공 API 호출
- Gemini Vision 연동
- 서버 파일 업로드와 카메라 권한
- 위치 권한과 지도 SDK
- 로그인, 저장, 보관함, 설정
- 실제 기관 전화 연결을 위한 API 연동, Spring Boot, Nginx, 데이터베이스

## 정보 구조

```text
홈 /
├── 이미지 식별 /identify/image
├── 외형 검색 /identify/shape
├── 검색 결과 /search/results
├── 의약품 상세 /drugs/:drugId
├── 증상 문서화 /symptoms
└── 응급의료기관 /facilities
```

모바일 하단 내비게이션은 `홈 / 알약 찾기 / 증상 기록 / 응급실` 네 영역으로 구성한다. 데스크톱에서는 동일한 항목을 상단 내비게이션으로 보여준다.

## 디자인 원칙

- 임시 브랜드명은 `알약케어`로 표시한다.
- 딥 네이비, 블루, 청록 계열을 사용하며 흰색·연한 청색 배경으로 대비를 조절한다.
- 주요 카드와 버튼은 20–28px 라운드와 얕은 그림자를 사용한다.
- 모바일 기준 최소 44px 터치 영역과 키보드 포커스를 보장한다.
- 모바일은 전체 폭 앱 셸, 데스크톱은 최대 1,180px 중앙 콘텐츠로 배치한다.
- 지도는 외부 데이터가 없는 SVG 스타일화 목업으로 제작한다.
- 약품·기관 정보에는 `예시 데이터`를 명시하고 처방이나 복용 지시처럼 보이는 문구를 사용하지 않는다.

## 데이터 경계

화면은 `src/data/mockData.js`의 로컬 데이터를 props로 받아 렌더링한다.

- `DrugRecord`: 제품명, 제조사, 주성분, 분류, 제형, 모양, 색상, 식별문자, 효능, 주의사항
- `FacilityRecord`: 기관명, 유형, 거리, 주소, 전화번호, 운영 상태, 지도 위치
- `SymptomNote`: 증상 목록, 발생 시점, 정도, 메모, 요약

추후 데이터 교체 대상은 식품의약품안전처 의약품개요 정보, 식품의약품안전처 의약품 낱알식별 정보, 국립중앙의료원 전국 응급의료기관 정보이다. API 엔드포인트와 응답 필드는 이번 단계에서 정의하지 않는다.

## 완료 기준

- 390×844, 768×1024, 1440×900 화면에서 주요 화면이 깨지지 않는다.
- 지정한 모든 라우트가 렌더링되고 내비게이션이 이동한다.
- 모바일 가로 스크롤이 발생하지 않는다.
- 이미지 식별, 약품 상세, 증상 기록, 응급의료기관 화면이 참고 이미지와 같은 정보 계층을 가진다.
- 단위 테스트와 `npm run build`가 통과한다.

## ver 1.0 개선 반영

기존 이미지 식별 화면은 다음의 짧은 흐름으로 확장한다.

```text
증상 복수 선택 → 앞면·뒷면 로컬 사진 미리보기 → 알약 찾기 → Mock 결과
                                                       ↓
                         복용하기 → 확인 모달 → 완료 상태만 표시
```

- `/identify/image`의 20개 증상 Chip은 초기 미선택이며 하나 이상 선택해야 `알약 찾기`가 활성화된다.
- 결과는 Router `state`로 전달하고 직접 접근·새로고침에는 `두통`, `발열` fallback을 사용한다.
- 대표 약품에는 `사용기한 확인 불가`를 표시하고, 복용 전 확인 모달에서 AI 식별 결과와 포장 확인 주의를 명시한다.
- 모든 주요 화면에는 `FACILITIES[0].phone`에서 숫자만 정규화한 `tel:0310001199` Mock 응급실 전화 링크를 노출한다.
- 사진은 브라우저의 object URL만 사용하고 교체·삭제·언마운트 시 URL을 해제한다.
- 모바일은 증상 4열 compact grid, 사진 2열, 하단 고정 액션을 사용하며 360px 이하에서 사진을 1열로 바꾼다.
